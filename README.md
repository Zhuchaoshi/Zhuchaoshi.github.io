# 住巢氏

**住巢氏**是由**广东元启企业管理有限公司**运营的设计品牌，2023年开始使用。

住巢氏主要围绕空间与环境开展设计相关业务，包括：

- 室内设计
- 建筑与空间设计
- 园林景观设计

## 品牌信息

- 品牌名称：住巢氏
- 运营主体：广东元启企业管理有限公司
- 品牌开始使用时间：2023年
- 业务方向：室内设计、建筑与空间设计、园林景观设计

## 关于运营主体

广东元启企业管理有限公司成立于2023年，为住巢氏品牌运营主体。
